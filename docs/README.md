# docs (SomeoneIsWorking fork)

This fork carries the RE notes of the [psx-spyro](https://github.com/SomeoneIsWorking/psx-spyro) port, which consumes
it as a submodule and reads guest addresses from its symbol map. Paths such as `game/...`, `titles/...` and
`docs/issues/...` in these files are psx-spyro paths. The decomp itself is upstream's; see the top-level README.

| file | what |
|---|---|
| `re-frontier.md` | the port's ordered RE evidence chain for this title (`re_frontier.py`) |
| `prior-art.md` | other work on this build, licences and what may be taken |
| `our-names.md` | the port's names where they differ from or add to this tree's symbol map |
